# Online Shopping System

## Project overview
This project models an Online Shopping System using a UML Class Diagram. It is a design assignment; a fully working application is not included.

## Scope
The proposed system models customer information, products and stock, shopping carts, orders, order items, and payment records.

## Main classes
- `Customer`
- `Product`
- `ShoppingCart`
- `CartItem`
- `Order`
- `OrderItem`
- `Payment`

## Relationships
The model includes customer-to-cart, customer-to-order, cart-to-cart-item, product-to-cart-item, order-to-order-item, product-to-order-item, and order-to-payment relationships. See `documentation/report_2_uml_class_diagram.pdf` for the details.

## Files
- `documentation/report_1_project_description.pdf`: project description and scope.
- `documentation/report_2_uml_class_diagram.pdf`: class descriptions and relationship explanations.
- `diagrams/uml_class_diagram.drawio`: editable diagram source.
- `diagrams/uml_class_diagram.png`: exported UML diagram image.
